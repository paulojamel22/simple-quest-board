![Foundry V14](https://img.shields.io/badge/Foundry-v14-orange)

Um módulo simples, leve e intuitivo para **Foundry VTT (v14)** focado em gerenciamento e exibição de quadros de missões (*Quest Board*) para os jogadores.

---

## ✨ Funcionalidades

* 📌 **Sincronização em Tempo Real:** Atualizações automáticas do status de missões para todos os jogadores conectados.
* 🛡️ **Controle do Mestre (GM):** Criação, edição e alteração de status de missões via interface amigável.
* 🧭 **Filtros Dinâmicos:** Jogadores podem filtrar missões ativas, concluídas ou arquivadas.
* 📦 **Compêndio de Macro Incluso:** Acompanha uma macro pronta no compêndio para abrir o Quadro de Missões com um clique na barra de atalhos.
* 🎨 **Interface Moderna (ApplicationV2):** Construído utilizando a API nativa `ApplicationV2` do Foundry V14 para alta performance e estabilidade.

---

## 🚀 Instalação

### Instalação via Manifest (Recomendado)

1. Abra o seu **Foundry VTT**.
2. Vá até a aba **Add-on Modules** e clique em **Install Module**.
3. Na caixa **Manifest URL** no rodapé da janela, cole o seguinte link:

```text
[https://github.com/paulojamel22/simple-quest-board/releases/latest/download/module.json](https://github.com/paulojamel22/simple-quest-board/releases/latest/download/module.json)
